## Dotfiles Commit Policy

**NEVER commit dotfiles changes without explicit user approval.**

When making changes to dotfiles (in `~/dotfiles`):

1. Make the necessary changes
2. Show the user what changed (git diff/status)
3. **Ask: "Is it working?"**
4. If yes, **ask: "Should I commit and push?"**
5. Wait for green signal (e.g., "commit it", "yes", "go ahead")
6. Only then commit and push

This ensures the user verifies all config changes work before they're saved.
